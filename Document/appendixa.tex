\chapter{Pedagogical Goals for Educational Technologies using Augmented Reality \label{appendix:a}}

A \ac{SLR} was performed as part of the literature review process guiding this research project, and the results of the codification phase of the review can be found in the following
repository:

\url{https://github.com/speregil/ar-survey-annex.git}

This \ac{SLR} codified a total of 67 different articles related to the use of \ac{AR} in educational settings. The analysis phase of the review focused on mapping what educational goals
were more prevalent in the design proposed in each surveyed project. This information was codified using the \ac{BRT} framework to understand the cognitive complexity of the goals
identified, while the goals themselves were codified using the verb + statement approach proposed by \textcite{fuchs_1982}.

The bibliographical information of all the surveyed articles was codified using the following structure shown in Table \ref{tab:A-1}.
